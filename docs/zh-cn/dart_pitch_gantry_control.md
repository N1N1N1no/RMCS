# 双直流电机龙门架（飞镖 Pitch）升降控制方案

> 场景：飞镖 Pitch 角由“龙门架”升降实现 —— 龙门/发射架两端各由一台直流电机（如 2006 类）+ 滚珠丝杆（如 1204）驱动升降，
> 两端负载（重心偏置、摩擦、装配误差）不一致时不能错位、不能卡滞，且要求运动平缓、Pitch 精度可控。
>
> 本文按“先把问题量化 → 机械第一道防线 → 控制架构 → 传感器选型 → 无外部传感器时的姿态估计 → 落地步骤”展开。

---

## 0. 先把“错位 / 平缓 / 精度”量化

定义两侧丝杆螺母位移（或丝杆转角）：

- 单侧位移：`x_i = θ_i / (2π) · p`，`p` 为丝杆导程（1204 即 p = 4 mm）；
- **共模高度（决定 Pitch）**：`h = (x_L + x_R)/2`，Pitch 由机构运动学映射 `pitch = f(h)`（标定成表/曲线，一般近似线性）；
- **错位（同步误差）**：`δ = x_L − x_R`，平台偏斜角 `α ≈ atan(δ / W)`，`W` 为两丝杆间距；
- **错位容限 `δ_max`**：由导轨间隙、结构弹性决定，量级通常是 0.1~0.5 mm；超过即产生导轨侧向力/卡滞/内应力。

设计目标：

1. **平缓**：参考轨迹加加速度（jerk）受限、无超调、低速不爬行、到位不振荡；
2. **不错位**：运动过程与静止保持都满足 `|δ(t)| < δ_max`；
3. **精度**：Pitch 误差（如 0.1°~0.2°）折算到 `h` 与 `δ` 的允许误差；
4. **安全**：软/硬限位、堵转卡死检测、上电找零、掉电不失位（或可靠复位）。

设计顺序（重要）：**先用机械让“错位自由度”可控（不产生内应力/卡滞），再用闭环消除残余错位，用前馈保证平缓。** 顺序反了，控制再好也会被机械卡死/振荡吃掉。

---

## 1. 机械层：第一道防线（先于控制）

错位的根因：两端负载/摩擦/装配不一致 + 双电机独立出力 → 两端速度差 → 位置差。
若平台被**刚性连接**，这个位置差不会“消失”，而是转化为导轨侧向力、丝杆弯矩、电机互搏；若平台**有间隙/弹性**，则表现为可见倾斜。

机械上要做的事：

1. **导向承担侧向力，丝杆只承担轴向**：用双导轨多滑块（如 MGN9×2）约束龙门，径向力/弯矩走导轨，丝杆不受弯 → 即使瞬时不同步，结构也不卡死、磨损可控。
2. **避免“过约束”**（2025 开源里真实踩过的坑）：丝杆螺母座如果**双边固连**在一块刚性板上，一旦两根丝杆的轴距/平行度有偏差，运动就会“憋死”。正确做法是**一边固定连接、另一边浮动/从动**，或加柔性联轴节，机械上允许微小不同步而不产生大内力。
3. **消隙**：滚珠丝杆选预紧型/双螺母，回程间隙压到 0.01~0.05 mm 量级；若用梯形丝杆（回差大），必须配负载侧反馈或机械消隙。
4. **两侧零位对齐**：装配时用水平仪/量块把两端螺母垫到同一高度，尽量对称。
5. **减载**：用配重/拉簧/气弹簧平衡大部分重力 → 负载随 Pitch 的变化小、电机工作在更线性区，天然更平缓、两侧更均衡。
6. **终极简化**：若载荷与布局允许，**单电机 + 同步带/轴同时驱动两根丝杆**，从机械上消灭同步问题（不少队伍这么做）。双电机方案的价值是扭矩大、布局灵活；若保留双电机，才需要第 3 节的电子同步。

> 判断系统是“1 自由度”还是“2 自由度”很关键：
> 刚性连接 + 导轨把两端锁死成近似 1-DOF → 错位以内力形式存在；
> 两端可相对错开（有间隙/弹性）→ 错位是真实几何自由度（2-DOF）。
> 下面两种控制拓扑分别对应这两种情况。

## 2. 控制层：推荐架构（同步给定 + 级联双环 + 交叉耦合同步）

### 2.1 拓扑选择（先回答“用哪种同步”）

| 机构情况 | 推荐拓扑 | 原因 |
| --- | --- | --- |
| 近似 1-DOF（刚性约束强） | **位置主环 + 力矩/电流从环**（主从力位混合） | 两端不可能独立错开，两个位置环会“互搏”产生内应力；让一个环定位置、另一个环跟随力矩（均载），简单可靠 |
| 真实 2-DOF（有间隙/弹性，龙门式常见） | **双位置环 + 交叉耦合（偏差耦合）同步** | 错位是真实几何量，必须用每侧位置反馈主动拉直 |
| 工程默认（飞镖龙门通常介于两者之间） | 交叉耦合同步为主，叠加电流/力矩监控 | 能主动纠偏，又能通过差动限幅避免在刚性方向打架 |

### 2.2 分层结构

```
        ┌────────────── 轨迹生成（共模，唯一参考）──────────────┐
        │  h_ref(t) 为 S 形 / 梯形（限加速度、限 jerk）           │
        │  xL_ref = xR_ref = h_ref（同一虚拟主轴 → 源头同步）     │
        └──────────────────────┬───────────────────────────────┘
                               │
        ┌──────────────────────▼───────────────────────────────┐
        │   交叉耦合同步环：δ = xL − xR                          │
        │   τ_sync = kp·δ + kd·δ̇ (+ki∫δ)，输出等大反向           │
        │   差动限幅：|τ_sync| ≤ τ_sync_max                      │
        └───┬───────────────────────────────────────┬──────────┘
            │ −τ_sync                               │ +τ_sync
   ┌────────▼────────┐                     ┌────────▼────────┐
   │ 左：位置环→速度环 │  ← 重力/摩擦/惯量    │ 右：位置环→速度环 │
   │    →力矩         │     前馈逐侧叠加       │    →力矩         │
   └────────┬────────┘                     └────────┬────────┘
            │                                       │
   ┌────────▼────────┐                     ┌────────▼────────┐
   │ 左丝杆+导轨+负载  │                     │ 右丝杆+导轨+负载  │
   └────────┬────────┘                     └────────┬────────┘
            └────────────── 位置反馈（丝杆末端/负载侧）──────────┘
```

各层职责与理由：

1. **轨迹生成（一次，共模）**
   只生成一个 `h_ref(t)`，两侧共享同一参考 → 命令层面不可能“一快一慢”。
   用 S 形/梯形并限制加速度与 jerk：加速度太大 → 冲击、跟随误差峰、同步误差峰一起出现；“平缓”首先由这里保证。
   到位判定用“容差 + 稳定延时”（沿用你双环实验里的到达判定思路），避免停在误差带内抖动。

2. **每侧级联双环（位置外环 → 速度内环）**
   - 内环速度环：反馈用电机/ESC 转速（1 kHz CAN），带宽高，能抑制负载突变；
   - 外环位置环：反馈优先取**丝杆末端/负载侧位置**（把背隙、丝杆误差、结构弹性都包进环内）；
   - 每侧独立整定（复用你 week2 的单侧双环经验），让单侧先能稳跟斜坡/梯形。

3. **交叉耦合同步环（回答“负载不一样怎么不错位”）**
   - 计算 `δ = xL − xR`，同步控制器输出差动力矩 `τ_sync`，**一侧加、另一侧减（等大反向）**：
     落后的一侧多出力、领先的一侧收一点力，直接把平台“拉平”；
   - 因为是差动修正，对共模高度 `h` 基本**解耦**——纠偏几乎不影响 Pitch；
   - 比“主从同步”（从侧只跟主侧）的动态同步误差小得多：主从在加速/负载突变时，从侧永远滞后一拍；
   - 加**差动限幅**：防止在刚性约束方向上两端“对顶”产生过大内力；
   - 需要消除稳态错位（如静态摩擦不对称）时给同步环加一点点积分，但要小心与位置环积分叠加引起振荡。

4. **前馈（决定“平缓”与“谁来出力”）**
   - **重力前馈**：负载随 Pitch/高度变化，且重心偏置导致两侧负载不对称 → 静态标定 `Tg_L(h)、Tg_R(h)` 曲线（逐点停在若干高度读稳态力矩/电流拟合；你仓库 `.script/identification/fit_gravity_torque.py` 就是这个思路，可复用），运动时按当前 `h` 查表前馈；
   - **摩擦前馈**：库仑 + 粘性项，恒速扫描标定（`.script/identification/fit_friction_velocity_pid.py` 同思路），消稳态误差、防低速爬行；
   - **加速度前馈**：`τ_ff = J_eff · a_ref`，减小加减速期跟随误差（间接减小动态同步误差）。
   - 效果：负载不对称时“该重的一侧多出力”由前馈承担，同步环只负责修正残差，而不是靠积分硬顶。

5. **到位与保持**
   - 到位后保持力矩 ≈ 重力前馈 + 极小 PI，防止重心偏置引起蠕变；
   - 丝杆若自锁（导程角小）可断电保持，否则掉电前先到最低位/安全位或加抱闸；
   - 方向反转做**回差补偿**（标定背隙 b，反转时命令多走 b），或让末段总是从同一方向逼近。

6. **安全与状态机**
   - 上电找零：慢速下行到限位开关，或顶到机械死点用“堵转检测”设零；
   - 软/硬限位；`|δ|` 超阈值 → 先减速纠偏，仍超限 → 报警停机；
   - 堵转/卡死检测：指令速度 ≠ 0、实测 ≈ 0、力矩饱和持续若干周期 → 判卡死停机（错位经常最终表现为卡死）；
   - 两侧电流监控：某侧持续饱和 → 说明机械或负载异常。

## 3. 传感器反馈怎么挑（“测什么、放哪里”）

### 3.1 选择原则

1. **内环要“快”，外环要“准”**：速度/电流内环用电机侧高带宽反馈（ESC 转速即可）；位置/同步外环用离负载尽量近的反馈；
2. **反馈尽量接近被控量**：被控的是“龙门高度/姿态（Pitch）”，所以每侧位置最好从丝杆末端/负载侧取，把背隙、丝杆导程误差、结构弹性都放进闭环里；
3. **姿态最好有绝对参考**：IMU（重力方向）是唯一“不用位置传感器就能拿到绝对姿态”的手段，且飞镖架通常板载、近乎免费；
4. **绝对式 vs 增量式**：增量式便宜但掉电丢位置、需每次找零；如果比赛“断电重启后要求直接可用”或“到位后失电保持”，倾向绝对式或可靠的掉电找零；
5. **分辨率不是瓶颈，反馈位置才是**：算例：导程 4 mm、14 bit 绝对编码器 ≈ 4/16384 ≈ 0.24 µm/step，分辨率绰绰有余；真正的误差来源是**背隙、装配零位、丝杆误差、结构弹性**——它们全在电机编码器“后面”，所以把编码器装在丝杆末端/负载侧比换更高位数更有效。

### 3.2 候选表

| 传感器 | 安装位置 | 测什么 | 优点 | 缺点/注意 | 典型用途 |
| --- | --- | --- | --- | --- | --- |
| ESC 转速反馈（C610/C620 CAN） | 电机 | 转子速度 | 免费、1 kHz、带宽高 | 无位置、转子侧 | 速度内环 |
| 电机端磁编码器（AS5600/MA730 等） | 电机尾轴/减速器输出 | 电机角位置 | 便宜、可绝对式 | 不含背隙与丝杆误差；增量需找零 | 半闭环位置 |
| **丝杆末端磁编码器** | 丝杆端部（螺母前） | 丝杆转角 | 覆盖齿轮/联轴误差；可选绝对式、掉电记忆 | 要轴向空间；防磁干扰 | 主位置/同步反馈（推荐） |
| 负载侧直线/拉线/磁栅编码器 | 平台/螺母 | 平台位移 | 背隙也包进环内，最接近被控量 | 贵、重、拖链、怕油污/粉尘 | 高精度闭环、标定基准 |
| IMU / 倾角传感器（常板载，装在龙门或发射管） | 移动件 | Pitch/Roll（重力参考） | 免费(板载)、绝对姿态 | 振动/平动加速度干扰；无绝对高度 | 姿态外环、标定 h→pitch、错位(Roll)监控、主动阻尼 |
| 限位开关 / 光电 | 行程两端 | 0/1 | 便宜可靠 | 只有端点信息 | 找零、安全 |
| 电流/力矩观测（软件） | — | 每侧出力 | 零成本 | 需电机模型 | 均载、堵转检测 |

### 3.3 推荐配置

- **保底**：每侧**丝杆末端绝对磁编码器**（做位置/同步外环）+ ESC 转速（速度内环）+ 上下限位找零 → 已能实现同步升降与防错位；
- **推荐**：在移动件/发射管上加一块 **IMU**：直接测 Pitch 做姿态校验与 h→pitch 标定，同时用 Roll 当“错位表”：两侧等高 ⇔ Roll ≈ 0，比靠两侧编码器对得更直接；
- **进阶**：每侧负载侧直线/磁栅把背隙包进环内——飞镖一般不需要，除非用梯形丝杆。

## 4. 没有外部传感器时，怎么估计龙门姿态（重点思考）

先盘点“内部”到底有什么信号（决定能估到什么程度）：

- M2006/M3508 + C610/C620：CAN 只回传**转速**（无位置、无电流）；
- 若用 GM6020 或自加编码器：才有角位置；
- 若自研驱动：才可能有电流/电压。

### 4.1 有电机端转速（最常见，M2006+C610 即此情况）

这是“半闭环软测量”，是**无外部传感器时的基线方案**：

1. **相对位置**：`x_i(t) = ∫ω_i dt · p/(2π)`（注意减速比），积分得到每侧位移；
2. **绝对零位**：上电找零 —— 慢速朝一端走到限位开关，或顶到机械死点用**堵转检测**（持续给指令但转速 ≈ 0、电流/出力上升）设零；
3. **姿态合成**：`h = (x_L+x_R)/2`，`δ = x_L−x_R`，`pitch ≈ f(h)`（用标定表/多项式）；
4. **误差源与对策**：
   - 积分漂移：单次通电、运动连续时漂移小；长时间或频繁启停会积累 → 掉电/定期重新找零；
   - 背隙：方向反转丢一段行程 → 标定回差 `b`，反转时命令多走 `b`，或末段单向逼近；
   - 丝杆导程误差/装配零位差：一次标定修正；
   - 打滑/堵转丢步：靠“位置指令在动但反馈不动 + 出力饱和”检测。

结论：这套估计在同一次通电、运动连续、无打滑的前提下，精度到“背隙 + 标定残差”量级，足够做同步控制——**但它是相对意义上的姿态，不是绝对姿态**。

### 4.2 只有电流/电压（连转速都没有）

必须诚实地说：**位置不可观**。

- 电机电学方程 `u = Ri + L·di/dt + K_e·ω` 里不出现位置，静止时 `i→0`，任意位置都给出同样的电流/电压 → 从 (u,i) 无法唯一重建 x；
- 可观性上，位置模态不在测量中，秩亏 → 位置是**不可观状态**；
- 能做的是：
  1. 堵转/到限位检测（电流骤升、指令下位置不动）→ 找零；
  2. 用电压方程做**反电动势/转速观测器**估 ω，再积分（漂移大，只能短时）；
  3. **两侧电流均衡**：把两侧出力 PI 到相等 → 若结构刚性（1-DOF），机械自动同步，负载均分，这已经“够用”；
  4. 但若有真实 2-DOF（有间隙/弹性），电流均衡**不能保证不偏**——因为没有任何信号告诉你平台歪没歪。

> 核心结论：没有位置/姿态反馈时，**共模高度与错位自由度本质不可观**。想“主动纠偏、保证不错位”，要么用机械把错位自由度约束成 1-DOF（刚性 + 浮动连接），要么加最便宜的传感器。这不是调参能解决的，是信息量的边界。

### 4.3 “没有外部传感器”但移动件带板载 IMU（飞镖架通常有）

IMU 加速度计直接感受重力矢量 → **发射管/龙门的 Pitch 与 Roll 是绝对可测的**（低频准，受振动与平动加速度干扰 → 低通/互补滤波）。这是唯一“不装位置传感器也能拿绝对姿态”的免费途径：

- Pitch 直接用来闭环（被控量本身就是 Pitch）；
- Roll 直接对应“错位角”：让 Roll → 0 等价于两侧等高，作为同步的目标/校验；
- 与 4.1 融合：电机积分（高频、相对）+ IMU（低频、绝对）做**互补滤波/卡尔曼**，得到一致的 `x_L、x_R、pitch` 估计；
- 发射瞬间振动大，姿态滤波要加“发射窗口屏蔽”，别把冲击当错位。

### 4.4 无外部传感器最小落地清单

```
上电找零（限位/堵转）→ 每侧转速积分出相对 x_i → 反转回差补偿
→ h/δ 合成 →（可选）IMU 的 Roll 校正 δ、Pitch 标定/闭环
→ 全程堵转/打滑检测兜底，掉电重新找零
```

局限要写进文档/汇报：积分漂移、背隙、打滑时“姿态估计会失真”，所以这是**可用但不绝对**的软测量，建议保留最小传感器作为校验与安全兜底。

---

## 5. 落地步骤（阶段化调试建议）

1. **机械检查**：两端零位等高、导轨平行度、丝杆预紧、是否过约束（单边固连/浮动）；
2. **单侧整定**：先让每侧“位置→速度”级联双环能稳跟梯形/斜坡（复用你双环实验的方法）；
3. **双侧同参考跑**：记录 `δ(t)、τ_L、τ_R`（用你 ValueBroadcaster → PlotJuggler 那套），看动态错位峰值与趋势；
4. **加交叉耦合同步环**：调 `kp_s/kd_s`，观察 δ 收敛速度、是否与位置环“打架”（用差动限幅压住）；
5. **加前馈**：重力曲线标定、摩擦标定、加速度前馈，逐项看跟随误差与两侧出力差下降；
6. **姿态闭环/校验**：有 IMU 则用 Roll 监控错位、标定 h→pitch（或直接 Pitch 闭环）；
7. **场景测试**：空载 / 一侧偏载 / 正反向到位与回差 / 断电重启找零 / 极限与堵转保护 / 发射振动后保持。

---

## 6. 一句话总结

**机械上**用导轨导向 + 防过约束（一端固连一端浮动）+ 防背隙，先把“错位自由度”处理成不会卡死的形态；
**控制上**用“同一个平滑轨迹 + 每侧级联双环 + 交叉耦合差动纠偏 + 重力/摩擦前馈”，让平缓来自轨迹与前馈、不错位来自同步闭环；
**反馈上**推荐“每侧丝杆末端绝对编码器（位置/同步）+ ESC 转速（内环）+ 移动端 IMU（姿态/标定/错位监控）”；
**完全无外部位置传感器时**用“转速积分 + 找零 + 回差补偿 +（可选）IMU 重力姿态”做软测量 —— 能覆盖大部分实战场景，但要清醒认识到：绝对位置与错位在无任何位置/姿态反馈时**不可观**，必须用机械约束或最小传感器兜底。
