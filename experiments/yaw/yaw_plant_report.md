# C 车 yaw 主模型辨识（2026-10-01）

## 测试与信号

- 只对 `deformable-infantry-omni-c` 增加了手动触发的 yaw 力矩测试。测试期间以 `+0.9, -0.9, -0.9, +0.9 N·m` 为一个周期，每相约 0.12 s，最多 8 周期。
- 遥控使能丢失、相对起点转角超过 0.12 rad、yaw 编码器速度超过 0.9 rad/s 时立即停止。测试前还要求 yaw 静止。
- 输入为电机反馈电流换算出的输出力矩；输出为电机编码器相对底盘的 yaw 角度。角速度采用云台 IMU 与底盘 IMU 的 yaw 角速度之差。
- 第一次测试完整运行 3.84 s；第二次在 2.55 s 触发转角保护，保留此前数据作独立验证。

## 辨识结果

在这两个测试位置附近，二阶线性主模型为：

\[
J\ddot q+B\dot q+d=\tau(t-T_d), \qquad
G(s)=\frac{e^{-T_d s}}{Js^2+Bs}.
\]

| 参数 | 估计值 | 单位 |
| --- | ---: | --- |
| 等效转动惯量 \(J\) | 0.1426 | kg·m² |
| 等效黏性阻尼 \(B\) | 1.3785 | N·m·s/rad |
| 测得力矩到角加速度的延迟 \(T_d\) | 约 0.003 | s |
| 速度时间常数 \(J/B\) | 0.1035 | s |
| 非零极点 \(-B/J\) | -9.666 | s⁻¹ |

训练仅采用第一次测试的第 1–5 个四相周期；第 0 周期作为启动过渡排除。按周期重采样得到的 95% 区间：\(J\) 为 0.1368–0.1487 kg·m²，\(B\) 为 1.332–1.434 N·m·s/rad。该区间只覆盖周期之间的变化，不覆盖电机力矩常数标定误差。

第一次测试最后两周期未参与拟合：角加速度预测 \(R^2=0.937\)，连续预测角度的 RMSE 为 0.00528 rad（0.303°）。第二次测试整段未参与拟合：角加速度预测 \(R^2=0.908\)。对第二次数据单独解算得 \(J=0.1444\) kg·m²、\(B=1.3923\) N·m·s/rad，与第一次接近。

两次测试的常值扰动力矩不同，第二次还因角度限位提前结束。因此，连续预测较长时间的绝对角度会积累偏差；这个模型适合当前工作点附近的短时运动预测和控制器初步设计。模型把非线性摩擦、电机内部电流动态、线缆回弹等合并进等效阻尼和扰动项，没有单独辨识刚度 \(k\)。

## 复现

```bash
python3 experiments/yaw/fit_yaw_plant.py
```

脚本读取两份 `yaw_plant_*.csv`，写入 `yaw_plant_fit.json` 和 `yaw_plant_fit.png`。可以修改脚本中的训练周期、差分窗口，再观察留出数据上的预测误差。
